5 · Export what you will print

The STL is the pattern exactly as shown, allowance included. It is written only if it is a closed, correctly wound solid — an open shell would slice into something you did not model.

Then, away from this application

  1. Print the pattern. If you cut it, print both halves and key them together.
  2. Fill, prime and sand it until it is glass smooth. Every scratch is copied into the mould, and from the mould into the part.
  3. Wax and apply release agent, build the parting board to the yellow line, then lay up the first glassfibre mould half.
  4. Strip the board, wax the flange, lay up the second half, then part the mould and remove the plug.
  5. Lay the final part up in carbon fibre inside the finished mould.
